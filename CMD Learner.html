Commands

Command الشرح
icacls C:\lab /deny user:(F) منع المستخدم بالكامل (Deny أقوى من Allow)
icacls C:\lab /remove:d user إزالة المنع (Deny)
net user عرض المستخدمين
ipconfig /all تفاصيل الشبكة
shutdown /r /t 0 إعادة تشغيل الجهاز
